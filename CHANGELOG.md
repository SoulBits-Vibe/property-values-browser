# Changelog

## 0.2.3

- Add a right-click rename action for property values.
- Renaming into an existing value merges them, including de-duplicating lists, after a confirmation that shows how many notes will change.
- Fix clicking a property or value so Search opens even when the Search tab was deferred or not fully loaded.
- Always reveal the Search sidebar when clicking a property or value, and show an error if Search cannot be opened.

## 0.2.2

- Remove clipboard fallback behavior.
- Add release asset provenance attestations.
- Clean up frontmatter typing.

## 0.2.1

- Publish a patch release with direct Obsidian assets.

## 0.2.0

- Add right-click delete actions for properties and values.
- Remove a property from all matching notes after confirmation.
- Remove a value from all matching notes after confirmation, removing the property when no values remain.

## 0.1.0

- Initial release.
