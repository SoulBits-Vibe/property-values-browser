# Changelog

## 0.3.1

- Clean up TypeScript typings for the community review linter.
- Document that the plugin reads markdown files in the vault to count property values.

## 0.3.0

- Right-click to rename a property or a value across matching notes.
- Renaming into an existing property or value merges them, de-duplicating lists, after a confirmation that shows how many notes will change.
- Clicking a property or value opens and reveals Search with the query set, even if the Search tab was deferred.

## 0.2.2

- Remove clipboard fallback behavior.
- Add release asset provenance attestations.
- Clean up frontmatter typing.

## 0.2.1

- Publish a patch release with direct Obsidian assets.

## 0.2.0

- Add right-click delete actions for properties and values.
- Remove a property from all matching notes after confirmation.
- Remove a value from all matching notes after confirmation, removing the property when no values remain.

## 0.1.0

- Initial release.
